# strata-mat

## afterimage/

"Retinal Bloom": a GLSL fragment shader and Figma Motion choreography guide
for the ARTECHOUSE "Afterimage" challenge.

- `retinal_bloom.frag` — shader (GLSL ES 1.00)
- `MOTION_GUIDE.md` — easing curves, timeline, u_time sync, Figma/WGSL port notes
- `preview.html` — browser harness with sliders (`python3 -m http.server`, then open `afterimage/preview.html`)
- `render_bloom.png`, `render_dormant.png` — reference frames at u_phase 1 and 0
